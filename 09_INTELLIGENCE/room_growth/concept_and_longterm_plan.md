## 1. 遠く: 3年後にどうなっていたいか

> **「子どもに使うものは、空くんと新米ママが選んだものなら安心」**
> ——同じ月齢の子を持つママたちがそう言って、迷ったときに見に来る場所になる。

**この人は実在の新米ママである**ことが最大の資産。作られたキャラではなく、
今まさに0歳児を育てている当事者。その一次体験を出せるのは我々だけで、
他のアカウントには真似できない。ここを軸にする。

- 商品を並べる人ではなく、**選ぶ基準を持っている人**として認識される
- フォロワー数を追わない。**「この人が薦めるなら買う」人の密度**を追う
- 楽天ROOM 内に閉じず、**外部(Instagram/Pinterest)から連れてくる**構造を持つ
  (CEO 指示: 「楽天ルームの中だけでは限界がある、という言葉は言わせない」)

## 2. コンセプト三点 (これが今後すべての判断基準)

### ① 誰に (Who)
**0〜6歳の子どもを育てている、忙しくて調べる時間がないママ。**
「安いもの」ではなく「失敗したくないもの」を探している層。

根拠: 現在のフォロワーはママ狙いの FOLLOW で構成済み (既存資産を捨てない)。

### ② 何を (What)
**子どもの口に入る・肌に触れるもの、そのママ自身をラクにするもの。**

| 出す | 出さない |
|------|----------|
| オーガニック食品・離乳食・お菓子 | 大人向け美容・サプリ |
| 肌に触れる日用品 (洗剤/タオル/衣類) | ファッション・アパレル |
| 時短家事・育児がラクになる道具 | 家電・ガジェット |
| ママ自身のご褒美 (少量) | 価格訴求だけの商品 |

**根拠 (7月実測)**:
- 唯一の高額成約 = **ミルポッシェ オーガニクス** (子ども向けオーガニック)
  売上¥6,460 → 報酬¥1,292 (**料率20%**)
- クリックはあるのに1件も売れない = ミューズラボ15clk / BAMBI WATER 12clk /
  オーガランド7clk / aquagarage 5clk (**全て大人向け美容・サプリ・アパレル**)

→ **このフォロワーは美容では買わない。子ども関連では買う。** データが商品軸を決めている。

### ③ どんな人として (How / 人格)
**「調べ尽くしてから買う、心配性なママ友」**

- 良い点だけでなく**合わない人**も書く (信頼の源泉)
- 実物写真で語る (楽天の商品画像をそのまま並べない)
- 価格を断定しない ([[collection_no_price_assertion_rule]] 厳守)

## 5a. 迷ったときの判断手順 (CEO 2026-08-01 指示)

> 「都度見直しているとまた判断に迷いが出ると思うので、その時は、遠くを見て
> 本来何をめざしていたのか。ここでコンセプトを変える必要があるか、それを検討しなさい。」

日々の数字を見ていると、必ず「この施策をやるべきか」で迷う。そのときは
**目の前の数字で決めない**。次の順で判断する。

1. **遠く(§1)を読む** — 3年後「子どもに使うものはこの人が選んだものなら安心」
   に、この施策は近づくのか、遠ざかるのか
2. **コンセプト三点(§2)に照らす** — 誰に/何を/どんな人として、から外れないか
   外れるなら、どれだけ短期の数字が良くても**やらない**
3. **それでも迷うなら「コンセプト自体を変えるべきか」を検討する**
   - 変えない: コンセプト内で打ち手を探し直す (通常はこちら)
   - 変える : **実データがコンセプトの前提を否定した時のみ**。
     例) 子ども関連を出し続けても成約が伸びず、別ジャンルで再現性のある
     成約が続いた場合 → §2 を書き換え、変更履歴に理由を残す
4. 判断した内容と理由を §6 変更履歴に必ず残す (後から検証できるように)

**禁止**: 短期の数字が悪いという理由だけでコンセプトをぶらす。
それが「資産の積み重ねにならない」原因だった (CEO 指摘)。

## 5b. 数値の取得方法 (次回も同じ値を再現するため)

フォロー/フォロワーの正確な総数は、ページングではなくこの1本で取れる:

```bash
curl -s -H "User-Agent: Mozilla/5.0" https://room.rakuten.co.jp/api/1000006606047125
# -> following_users / followers / collections / last_collect
```

※ `/followers?limit=100` を辿る方式は途中で打ち切られ**過少値**になる。
  初版はこの誤りで「フォロワー18,000 / フォロー34,909」と記載していた
  (follow_history.json の累積件数を現在のフォロー数と取り違えた)。
  2026-08-01 に実測 42,076 / 21,237 へ訂正。
