# 楽天ROOM 収益ランプ計画 — 月10万円粗利への道筋

**管理者**: サイバー(単独・全権委任 2026-07-21) / **最終更新**: 2026-07-23
**ゴール**: インフルエンサー粗利(アフィリ報酬) **月10万円**

---

## 0. 収益の連鎖 (KPIツリー)

```
月間報酬 = クリック数 × クリック単価 × (成約が乗る係数)
  クリック数   = 投稿露出 × フォロワー到達 × CTR
  クリック単価 = Σ(成約報酬) / クリック  ← 20%高料率品が支配的
```

**実測 (2026-07-23 時点)**
| 指標 | 現状 | 10万円に必要 | 倍率 |
|------|------|------------|------|
| 月間報酬 | ¥1,357 (7月MTD) | ¥100,000 | **74x** |
| クリック/日 | 2.3 | 77 (単価¥42想定) | **33x** |
| クリック単価 | ¥26 (希釈後) | ¥42+ (20%品集中) | 1.6x |
| POST/日 | 7〜21 (不安定) | 40+ (安定) | — |
| FOLLOW/日 | 322 (検証済) | 維持〜増 | ✅ |
| フォロワー | 20,151 | 増やすほど到達↑ | 進行中 |

**核心**: 7月報酬¥1,357の**95%が1件のミルポッシェ(料率20%)**。
→ ①露出(POST)を安定増、②20%品にプール集中、③CTR(投稿クリエイティブ)改善 の3レバー。

## 2. 今週の方向性 (7/23〜7/31)

**テーマ: 露出の安定化 — POSTを詰まりなく40/日回す**

1. **POST基盤の安定化** (最優先): VM Chrome/HTTPサーバのハングを解消。
   これが解けないと露出が増えずクリックが増えない。
2. **FOLLOW維持**: 1時間枠95件のペースで300/日を継続 (検証済・虚偽ゼロ)。
3. **20%プール集中**: high_rate_v2 を厚くし、投稿の料率期待値を上げる。
4. **監視の実運用**: patrol critical が Slack に届くことを毎日確認。

**今週の数値ゲート**: POST 40/日 到達・クリック 5→10/日・報酬 +¥1,500。

## 3. 今日の方向性 (日次ルーチン)

毎日 `python ops/daily_direction.py` で以下を自動採点する:

| 機能 | 日次目標 | 判定基準 |
|------|---------|---------|
| POST | 40 | public API 実投稿数 |
| FOLLOW | 300 | following_users ID突合(検証済) |
| LIKE | 150 | like履歴 |
| FB | 50 | followback実数 |
| クリック | 10 | アフィリCSV (取込時) |

**オフトラック時**: 原因を即特定して当日中に手当て(先送り禁止)。
**基盤障害時**: patrol critical が Slack #web-cyber_marke_clow に自動通知(実効化済)。
